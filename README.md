# DKW(早慶同)親睦麻雀大会｜GitHub Pages版

開催日：2026年10月24日

## この初版に入っている機能

### 参加者向け（閲覧専用）
- 第1〜5回戦の組み合わせ
- 卓ごとの最新得点
- 個人成績・総合順位
- 大学順位（各大学8名全員の合計）
- 10秒ごとの自動更新 + 手動更新

### 幹事向け
- 「幹事用」からパスワードだけでログイン
- 参加者24名の氏名登録
- 1卓ずつ得点入力・修正・クリア
- 4人合計が0.0でない場合は保存不可
- 第1〜4回戦の入力状況チェック
- 第5回戦の自動作成
  - 第1〜4回戦の最新得点を再取得
  - 24卓すべて入力済みか検査
  - 個人総得点順に4人ずつ6卓へ配置
  - 同点者だけランダム
  - プレビュー後に確定
- 第5回戦の席順は
  - 1位＝東（初期設定）
  - 1位＝北
  を幹事画面で選択可能

## Supabase接続
`app.js` 冒頭に今回の Publishable key と Project URL を設定済みです。
Secret key / service_role key は一切使用していません。

## GitHub Pagesへ載せるファイル
同じフォルダに以下3ファイルを置いてください。

- `index.html`
- `style.css`
- `app.js`

## 重要
この版は大会コア機能の初版です。
GitHubへ公開した後、実際に以下をテストしてから本番仕様をFIXします。

1. 参加者名を1人登録 → 別端末でも反映
2. 1卓の得点を保存 → 別端末でも反映
3. 別の卓を保存しても先ほどの卓が消えない
4. 得点修正・クリア
5. 24卓入力後の第5回戦作成
6. 第5回戦確定後の得点入力
7. スマホ表示
